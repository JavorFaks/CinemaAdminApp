About

This application is an administration system for a cinema network, intended for staff who keep records of cinemas, halls, movies and ticket reservations.

It lets you create, view, edit and delete cinemas, the halls within them, the movies on offer, and reservations tied to a specific hall and movie, with pagination, sorting and filtering.

Technologies

Angular Angular Material Spring Boot Spring Data JPA PostgreSQL

About the project

This project was developed as part of the Multi-tier Application Development course (Razvoj višeslojnih aplikacija) at the Faculty of Technical Sciences, University of Novi Sad, Information Systems Engineering.
